<a name="x5engine.imShowBox"></a>
## x5engine.imShowBox(settings, [startIndex], [launcher]) ⇒ <code>bool</code>

Shows a ShowBox using the provided settings.

**Kind**: global function  
**Returns**: <code>bool</code> - Always returns `false`, so the function can be used in an `onclick` handler.

| Param | Type | Default | Description |
| --- | --- | --- | --- |
| settings | <code>object</code> |  | ShowBox settings. Unspecified values use the ShowBox configuration generated by WebSite X5. |
| settings.allowFrameTransparency | <code>boolean</code> |  | Allow transparency in iframe content. |
| settings.autoplay | <code>boolean</code> |  | Automatically advance through media. |
| settings.autoplayTime | <code>number</code> |  | Milliseconds between automatic transitions. |
| settings.background | <code>string</code> |  | Overlay background color. |
| settings.backgroundBlur | <code>number</code> |  | Amount of blur applied to the page behind the ShowBox. |
| settings.borderWidth | <code>object</code> |  | Border widths, with numeric `top`, `left`, `bottom`, and `right` properties. |
| settings.borderColor | <code>string</code> |  | Border color. |
| settings.borderRadius | <code>number</code> |  | Border radius. |
| settings.boxColor | <code>string</code> |  | Internal background color. |
| settings.boxClass | <code>string</code> |  | CSS class assigned to the media box. This is the public property consumed by the implementation. |
| settings.effect | <code>string</code> |  | Opening effect: `none`, `fade`, `move`, `zoom`, `hide`, or `custom`. |
| settings.customEffect | <code>string</code> |  | CSS class applied when `effect` is `custom`. |
| settings.fontFamily | <code>string</code> |  | Description font family. |
| settings.fontStyle | <code>string</code> |  | Description font style. |
| settings.fontWeight | <code>string</code> |  | Description font weight. |
| settings.fontSize | <code>string</code> |  | Description font size. |
| settings.innerBorder | <code>number</code> |  | Internal padding in pixels. |
| settings.shadow | <code>string</code> |  | ShowBox shadow. |
| settings.sound | <code>boolean</code> |  | Enable sound for media that supports it. |
| settings.textColor | <code>string</code> |  | Description text color. |
| settings.textAlignment | <code>string</code> |  | Description text alignment. |
| settings.onClose | <code>function</code> |  | Callback invoked when the ShowBox closes. |
| [startIndex] | <code>number</code> | <code>0</code> | Index of the media initially shown. |
| [launcher] | <code>DOMObject</code> |  | DOM element used as the starting point for zoom effects. |

### Media

`settings.media` is an array. Each item supports the following properties:

| Property | Type | Description |
| --- | --- | --- |
| type | <code>string</code> | Media type: `image`, `video`, `sound`, `youtube`, `vimeo`, or `html`. |
| url | <code>string</code> | URL of the media. |
| width | <code>number</code> | Width in pixels. |
| height | <code>number</code> | Height in pixels. |
| html | <code>string</code> | HTML loaded when `type` is `html`. |

On iPhone and iPad, a PDF may be opened in a new browser tab instead of being displayed inside the ShowBox.

### Controls and transitions

| Setting | Type | Description |
| --- | --- | --- |
| buttonLeft | <code>string</code> | HTML for the previous-media button. |
| buttonRight | <code>string</code> | HTML for the next-media button. |
| buttonClose | <code>string</code> | HTML for the close button. |
| buttonEnterFS | <code>string</code> | HTML for the enter-fullscreen button. |
| buttonExitFS | <code>string</code> | HTML for the exit-fullscreen button. |
| buttonZoomIn | <code>string</code> | HTML for the zoom-in button. |
| buttonZoomOut | <code>string</code> | HTML for the zoom-out button. |
| buttonZoomRestore | <code>string</code> | HTML for the reset-zoom button. |
| windowPadding | <code>number</code> | Margin from the viewport. |
| showProgress | <code>boolean</code> | Show the media index when more than one item is present. |
| fullScreenEnabled | <code>boolean</code> | Enable fullscreen when supported by the browser. |
| zoomEnabled | <code>boolean</code> | Enable zoom for image media. |
| showThumbs | <code>boolean</code> | Show thumbnails when more than one item is present. |
| thumbSize | <code>number</code> | Thumbnail size. |
| transitionEffect | <code>string</code> | Transition between media: `fade`, `horizontalSlide`, `verticalSlide`, `zoom`, `elasticFromTop`, `elasticFromBottom`, `elasticFromRight`, `elasticFromLeft`, `bounceFromTop`, `bounceFromBottom`, `bounceFromLeft`, `bounceFromRight`, or `rotateLinear`. |

**Example**

```js
x5engine.imShowBox({
    media: [
        { type: "image", url: "myimage1.jpg", width: 800, height: 400 },
        { type: "image", url: "myimage2.jpg", width: 800, height: 600 }
    ],
    effect: "custom",
    customEffect: "my-showbox-effect",
    onClose: function () {
        console.log("ShowBox closed");
    }
});
```
